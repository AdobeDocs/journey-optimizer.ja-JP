# 動的コンテンツの基本を学ぶ {#start-dynamic-content}

>[!BEGINSHADEBOX]

**このページ：**&#x200B;動的コンテンツで、プロファイル属性、コンテキストイベント、オーディエンスから構築された条件付きルールを使用して、ターゲット プロファイルにメッセージを適応させる方法を説明します。

>[!ENDSHADEBOX]

>[!CONTEXTUALHELP]
>id="ajo_conditions_list"
>title="条件"
>abstract="条件ルールを使用すると、プロファイル属性、コンテキストイベントまたはオーディエンスに基づいて、メッセージに複数のコンテンツバリアントを表示できます。"

動的コンテンツを使用すると、プロファイル属性、コンテキストイベントまたはオーディエンスで構成できる&#x200B;**条件付きルール**&#x200B;に基づいてメッセージのコンテンツを調整できます。 条件付きルールは、パーソナライゼーションエディター内のビジュアルルールビルダーで作成し、ジャーニーやキャンペーンで後から再利用するために保存できます。

条件付きルールは、E メールデザイナーやパーソナライゼーションエディターで利用し、メッセージでターゲット設定されたプロファイルに適応する&#x200B;**動的コンテンツを作成**&#x200B;することができます。

>[!TAB 概要]

**TL;DR**

ここでは、Journey Optimizerの動的コンテンツを紹介します。プロファイル属性、コンテキストイベント、オーディエンスから構築された条件付きルールにより、メッセージをターゲットのプロファイルに適応させる方法を解説します。

**インテント**

* 動的コンテンツとは何か、静的メッセージコンテンツとの違いを理解する
* 動的コンテンツの2つのエントリポイント（メールDesignerとパーソナライゼーションエディター）を特定します
* 条件付きルールの作成や動的コンテンツの作成に適したガイドに移動します

>[!TAB 用語集]

* **動的コンテンツ**：条件付きルールに基づいて適応するメッセージコンテンツ。定義された条件が満たされているかどうかに応じて、異なるコンテンツが異なるプロファイルに表示されます。 *（製品固有）*
* **条件付きルール**: プロファイル属性、コンテキストイベント、またはオーディエンスから作成された一連の基準で、プロファイルが受け取るコンテンツバリアントを決定します。 *（製品固有）*
* **ビジュアルルールビルダー**：条件ルールの作成と保存に使用されるパーソナライゼーションエディター内のインタラクティブキャンバス。 *（製品固有）*

>[!TAB 用語]

* **正規名：**&#x200B;動的コンテンツ – バリアント：条件付きコンテンツ、パーソナライズされたコンテンツ
* **類義語：** 「条件付きルール」 = 「条件」（UIのラベル付き）
* **動的コンテンツ（**&#x200B;条件ルールに基づいてプロファイルごとに適応するコンテンツ）≠静的コンテンツ（条件に関係なくすべての受信者に表示される同じコンテンツ）を混同しないでください

>[!TAB FAQ]

**Q：条件ルールで使用できる条件の種類は何ですか？**

条件付きルールは、プロファイル属性、コンテキストイベント、オーディエンスメンバーシップなどから構築できます。

**Q：動的コンテンツの作成に条件付きルールはどこで使用できますか？**

電子メールDesigner（コンポーネントバリエーションを作成する場合）とパーソナライゼーションエディター（条件を使用して式ブロックをラップする場合）で。 両方のエントリポイントは、リンクされたページでカバーされています。

**Q：条件付きルールは、ジャーニーとキャンペーン間で再利用できますか？**

はい。 条件付きルールを保存して、ジャーニーやキャンペーンをまたいでさらに再利用できます。

>[!ENDTABS]
