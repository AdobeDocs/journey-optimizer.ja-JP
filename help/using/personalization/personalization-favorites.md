# お気に入りに属性を追加 {#fav}

>[!BEGINSHADEBOX]

**このページ：** Adobe Journey Optimizerでパーソナライゼーション式を作成する際に、お気に入りメニューで属性を追加、アクセス、削除して、すばやく再利用する方法を説明します。

>[!ENDSHADEBOX]

お気に入りメニューに異なる属性を追加すると、最も頻繁に使用する項目にすばやくアクセスできます。 属性をお気に入りに追加するには、「...」メニューをクリックし、「**[!UICONTROL お気に入りに追加]**」を選択します。

<!--
![](assets/favorite-option.png)
-->

お気に入りの項目にアクセスするには、左ウィンドウの&#x200B;**[!UICONTROL お気に入り]**&#x200B;メニューを使用します。

このリストから、パーソナライゼーションオブジェクトを現在の式にすばやく追加できます。

<!--
![](assets/favorite-list.png)
-->

お気に入りリストに項目を表示する必要がなくなった場合は、お気に入りから削除します。

<!--
![](assets/favorite-remove.png)
-->

>[!TAB 概要]

**TL;DR**

このページでは、頻繁に使用する属性をパーソナライゼーションエディターのお気に入りメニューに追加し、すばやく再利用するためにアクセスし、不要になったときに削除する方法について説明します。

**インテント**

* お気に入りメニューにパーソナライゼーション属性を追加して、すばやくアクセスできます
* エディターの左ペインの「お気に入り」メニューからお気に入りの属性にアクセスします
* お気に入りリストから属性を削除

>[!TAB 用語集]

* **お気に入りメニュー**: パーソナライゼーションエディターの左側のナビゲーションペインにある専用セクションで、ユーザーがお気に入りとしてマークした属性にすばやくアクセスできるため、式の作成を高速化できます。 *（製品固有）*

>[!TAB 用語]

* **正規名：**&#x200B;お気に入り – バリエーション：お気に入りメニュー、属性のお気に入り、お気に入り属性
* **正規名：**&#x200B;お気に入り – バリエーション：お気に入りメニュー、お気に入り属性

>[!TAB FAQ]

**Q：お気に入りに属性を追加するにはどうすればよいですか？**

ナビゲーションパネルの属性の横にある省略記号メニューをクリックし、**お気に入りに追加**&#x200B;を選択します。

**Q：お気に入りの属性はどこにありますか？**

パーソナライゼーションエディターの左側のペインの&#x200B;**お気に入り** メニューで。

**Q：お気に入りから属性を削除するにはどうすればよいですか？**

左側のペインの&#x200B;**お気に入り** メニューから、項目をお気に入りから削除します。

>[!ENDTABS]
