# コンテンツカードの基本を学ぶ {#get-started-content-card}

>[!BEGINSHADEBOX]

**このページ：**&#x200B;コンテンツカードが、モバイルアプリや web サイト内で、パーソナライズされた押し付けがましくないメッセージを直接配信します。これにより、ユーザーの行動を妨げることなく、コンテキストに沿ってユーザーのエンゲージメントを高めることができます。

>[!ENDSHADEBOX]

コンテンツカードは、Adobe Journey Optimizer の新しいデジタルメッセージ機能で、パーソナライズされた魅力的なコンテンツをモバイルアプリや web サイト内で直接配信します。 従来のプッシュ通知とは異なり、コンテンツカードはユーザーインターフェイスにシームレスに統合され、ユーザーのインタラクションとエクスペリエンスを向上させる、永続的で非割り込み型の更新を提供します。

この機能により、マーケターは、関連性の高いリッチメディアコンテンツをユーザーに提示し、エンゲージメントを向上させ、ユーザージャーニーを中断することなく重要なメッセージを確実に確認できるようにします。

## ユースケース

コンテンツカードの効果は、メッセージを瞬時に中断するのではなく、ユーザーが自分のペースでアクションできるようにしたい場合に最も高くなります。

| 利点 | 理由 | ユースケースの例 |
| --- | --- | --- |
| 永続的な可視性 | カードは、利用者が解除するまでアプリまたはweb サイトに残ります | 継続的なプロモーション、機能ハイライト |
| 邪魔にならない配信 | ユーザーを中断する代わりにインターフェイスに統合します | パッシブ更新を他のコンテンツと並行して表示 |
| プッシュオプトインなしで動作 | プッシュ通知の同意にかかわらず、アプリ内またはオンサイトで配信 | プッシュ通知を無効にしたユーザーにリーチ |
| 視覚的にリッチなメッセージ | メディアとcall-to-action ボタンをサポート | 画像と「Shop now」ボタン付きの製品スポットライト |

## 使用しない場合

コンテンツカードは、ユーザーが自分のペースでコンテンツを表示できるようにすることを目的としているため、あらゆるシナリオに適しているわけではありません。 次のような状況では、別のチャネルを検討してください。

* ユーザーはアプリまたはweb サイトを時間内に開いてカードを確認できないため、メッセージは時間制限のあるアラートです
* コンテンツカードはアプリまたはweb サイト内でのみ表示され、非アクティブなユーザーには表示されないため、ターゲットユーザーは非アクティブです
* コンテンツは機密性が高い、または永続的で目に見えるカードでは保証できない安全な処理が必要です
* メッセージには、フラッシュセールなどの緊急call to actionが必要です。この場合、プッシュ通知やメールにより迅速に対応できます
