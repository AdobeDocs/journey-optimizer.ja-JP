# ジャーニーの種類と選択ガイド {#journey-types-selection}

[!DNL Adobe Journey Optimizer]は4つのジャーニータイプをサポートしており、それぞれ異なるエントリメカニズムとビジネスシナリオ用に設計されています。 このガイドでは、相違点を理解し、ユースケースに適したタイプを選択するのに役立ちます。

## ジャーニータイプの概要 {#journey-types}

>[!BEGINTABS]

>[!TAB 単一ジャーニー]

**使用するタイミング：** リアルタイムのイベントトリガーエクスペリエンス

**単一ジャーニー**&#x200B;は、特定のアクション（購入、アプリのログイン、フォーム送信）が発生すると、個別にトリガーされます。 プロファイルはリアルタイムで一度にひとつずつ入力されるため、即座に行動主導の応答を行うのに適しています。

**購入後の注文の確認、購読時のウェルカムメール、閲覧時のカート放棄、パスワードリセット通知など、**&#x200B;に最適です。

➡️ [ イベントについて学ぶ](../event/about-events.md) | [購読者へのメッセージのユースケース ](message-to-subscribers-uc.md)

>[!TAB  オーディエンスジャーニーの読み取り]

**使用するタイミング：** スケジュール済みキャンペーンをオーディエンスセグメントに送信

**オーディエンスジャーニーを読む**&#x200B;は[!DNL Adobe Experience Platform]人のオーディエンスから始まり、すべてのプロファイルに同時にメッセージを一括送信します。 このタイプのジャーニーは、スケジュール型の大規模なコミュニケーションに適しています。

**毎月のニュースレター、ターゲットセグメントに対するプロモーション施策、製品のお知らせ、季節ごとのマーケティング施策に最適：**&#x200B;です。

➡️ [ オーディエンスの読み取りに関する学習](read-audience.md) | [ オーディエンスの基本を学ぶ](../audience/about-audiences.md)

>[!TAB  オーディエンス選定ジャーニー]

**使用するタイミング：** オーディエンスメンバーシップの変更に対するリアルタイム応答

プロファイルが特定のオーディエンスに適格である（または離脱する）場合の&#x200B;**オーディエンス選定ジャーニー**&#x200B;のトリガー。 プロファイルは、基準を満たす個々のプロファイルをリアルタイムで入力するため、顧客の行動が変化した際に、すばやくエンゲージメントすることができます。

**お客様が非アクティブになった場合の**&#x200B;のVIP階層アップグレード通知、リエンゲージメント、最初の購入のお祝いメッセージ、お客様が移動した場合の地理的ターゲティングに最適です。

➡️ [ オーディエンス選定について学ぶ](audience-qualification-events.md) | [ オーディエンスの作成](../audience/creating-a-segment-definition.md)

>[!TAB  ビジネスイベント ジャーニー]

**使用するタイミング：**&#x200B;複数の顧客に影響するビジネス条件

**ビジネス イベント ジャーニー**&#x200B;は、複数のプロファイルに同時に影響を与えるビジネス レベルのイベント （在庫更新、天気予報、価格変更）によってトリガーされます。 これらは、個々のアクションではなく、より広範なビジネス状況に対応します。

**最適：**&#x200B;興味のある顧客への低在庫アラート、フラッシュセールのお知らせ、天候に応じたプロモーション、値下げ通知、商品の再入荷アラート。

➡️ [ ビジネスイベントについて学ぶ](../event/about-creating-business.md) | [ エントリ管理](entry-management.md)

>[!ENDTABS]

## 決定ガイド：ジャーニータイプの選択 {#decision-guide}

次の決定ツリーに従って、ユースケースに適したジャーニータイプを選択します。

### ステップ 1：ジャーニーのトリガーとは？

* **お客様が特定のアクションを実行する** （購入、クリック、ログイン） → ステップ 2に進む
* **時間/スケジュール** （特定の時間または定期的に送信） → **オーディエンスジャーニーの読み取りを使用**
* **顧客ステータスの変更** （セグメントへの参加/離脱） → ステップ 3に進む
* **ビジネス状況** （在庫レベル、価格変更、天候） → **ビジネスイベント ジャーニーを使用**

### ステップ 2：個々の顧客行動トリガー

* **即時のリアルタイム応答が必要ですか？**
   * はい→ **単一ジャーニーを使用**
   * スケジュールされた実行でオーディエンスジャーニーを読み取ることを検討する→はいない

### 手順3：顧客ステータスの変更

* **顧客がセグメントにエントリまたは離脱したときに応答する必要がありますか？**
   * はい→ **オーディエンス選定ジャーニーを使用**
   * いいえ。→ イベント付きの単一ジャーニーを検討またはオーディエンスフィルター付きのオーディエンスを読み取り

### ユースケース別のクイック選択

| 目標 | 推奨されるジャーニータイプ | なぜ |
|-----------|------------------------|-----|
| 購入後に注文確認を送信する | 単一 | 個々のアクションに対する即時対応 |
| 購読者に毎月ニュースレターを送る | オーディエンス読み込み | スケジュール済みバッチ通信 |
| VIPのステータスに達したことを通知する | Audience Qualification | ステータスの変更に対するリアルタイムの対応 |
| 在庫が少ない商品について顧客に通知する | ビジネスイベント | ビジネス状態が複数の顧客に影響を与える |
| 新規アプリユーザーを歓迎する | 単一 | 登録イベントがトリガー |
| 非アクティブな顧客のリエンゲージメント | Audience Qualification | 非アクティブなセグメントエントリに応答 |
| ターゲットセグメントへの季節ごとのプロモーション | オーディエンス読み込み | スケジュールされたキャンペーンからオーディエンスへ |
| Flash販売のお知らせ | ビジネスイベント | ビジネス上の意思決定が複数の顧客に影響を及ぼす |

>[!NOTE]
>
>どのタイプを選択すればよいかわからませんか？ イベントベースのエクスペリエンスの場合は&#x200B;**単一ジャーニー**&#x200B;から開始し、スケジュールされたキャンペーンの場合は&#x200B;**オーディエンスジャーニー**&#x200B;を読み取ります。これらは、最も一般的なユースケースをカバーしています。

## ジャーニータイプの詳細比較 {#journey-types-comparison}

この表を使用して、ジャーニーのタイプをすばやく比較し、ユースケースに適したものを選択します。

| 縦横 | 単一ジャーニー | オーディエンスジャーニーを読む | オーディエンス選定ジャーニー | ビジネスイベントジャーニー |
|--------|------------------|------------------------|--------------------------------|------------------------|
| **入口メカニズム** | 個別イベントトリガー | スケジュールバッチ | Real-time audience membership change | ビジネスレベルのイベント |
| **エントリのタイミング** | イベントが発生するたびにリアルタイムに | スケジュール済み（1回限りまたは定期的） | 選定が行われると、リアルタイムで | ビジネスイベントがリアルタイムで発生する |
| **プロファイルエントリ** | 一度に1回 | 一括（バッチ） | 一度に1回 | 複数プロファイルの同時使用 |
| **トリガーソース** | 顧客の行動（購入、クリック、ログイン） | 時間ベースのスケジュール | オーディエンスメンバーシップ（入口/出口） | 経営状況（在庫、天候、価格） |
| **最適** | トランザクションメッセージ、行動応答 | マーケティング施策，ニュースレター | ロイヤルティプログラム、ライフサイクルステージ | 在庫アラート、プロモーション、ビジネス状況 |
| **使用日時** | 必要な個々のアクションへの迅速な対応 | スケジュールどおりに大規模なオーディエンスセグメントにリーチ | 顧客ステータスの変更への対応 | ビジネスイベントは複数の顧客に影響します |
| **例** | 注文確認、パスワードリセット | 月刊ニュースレター、季節キャンペーン | VIPのアップグレード、非アクティビティアラート | 低い在庫アラート、フラッシュセール、価格低下 |
| **再エントリ** | 設定可能（プロファイルごとに複数のエントリを許可） | 各プロファイルは、実行ごとに1回入力されます | 選定イベントごとに設定可能 | 複数のプロファイルが同じイベントの影響を受ける可能性があります |
| **データ要件** | トリガーデータを使用したイベントスキーマ | [!DNL Adobe Experience Platform]人のオーディエンス | ストリーミングまたはバッチオーディエンス | ビジネスイベントスキーマ |
