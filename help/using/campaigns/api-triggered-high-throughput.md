# API トリガーメールキャンペーンの高スループットモードのアクティブ化 {#high-throughput}

>[!BEGINSHADEBOX]

**このページでは：** API トリガーのキャンペーンに対して高スループットモードを有効にします。これにより、プロファイルに頼ることなく、最大5000 トランザクション/秒（電子メール）または最大1500 トランザクション/秒（プッシュ）で、非常に大規模なリアルタイムのトランザクションメッセージを送信できます。

>[!ENDSHADEBOX]

ハイスループットモードは、**非常に大規模なリアルタイムのトランザクションメッセージ**&#x200B;を必要とする組織向けに設計されています。 通常の API トリガーキャンペーンとは異なり、高スループットキャンペーンは Adobe プロファイルとは独立して動作し、異なる設定モデルが必要です。

このページでは、高スループットキャンペーンと標準の API トリガーキャンペーンの違い、設定要件、各モードを選択するタイミングについて説明します。

## ガードレールと制限

&#x200B;* **アクセス** - 高スループットトランザクションメッセージのアドオンのライセンスを持つ組織が米国地域でのみ使用できます。

&#x200B;* **チャネル**：電子メールとプッシュ通知で使用できます。

&#x200B;* **スループット**:

   &#x200B;* **電子メール** - 1秒あたり最大5000 トランザクションです。
   &#x200B;* **プッシュ** - 1秒間に最大1500 トランザクション。 500 TPS （基本）、1000 TPS、1500 TPSの階層化スループットレベルを使用できます。 より高額の場合は、適切なアドオンの使用権限が必要です。

&#x200B;* **パーソナライゼーション**：

   &#x200B;* すべてのパーソナライゼーションは、**コンテキストデータ**&#x200B;として API ペイロードに含める必要があります。 [コンテキストデータを使用したコンテンツのパーソナライズ方法の詳細情報](../campaigns/api-triggered-campaign-content.md#contextual)
   &#x200B;* プロファイルベースのパーソナライゼーションはサポートされていません。 プロファイル変数を使用すると、検証エラーが発生します。

&#x200B;* **パーソナライズされたチャネル設定** - [プロファイルベースのパーソナライゼーション](../email/surface-personalization.md)を使用するチャネル設定は、高スループットキャンペーンでは使用できません。 プロファイルパーソナライゼーションがないサーフェスのみを使用できます。

&#x200B;* **API エンドポイント** - 高スループットキャンペーンでは、標準の API トリガーキャンペーンとは異なるエンドポイントが使用されます。 詳しくは、[API トリガーキャンペーンの実行](../campaigns/trigger-campaigns.md#trigger)を参照してください。

&#x200B;* **キャンペーンの排他性** - 高スループットキャンペーンでは、アドビのプロファイルは使用されません。 プロファイルが存在するかどうかに関係なく、メッセージは配信されます。

  さらに、キャンペーンは、プロファイル対応とプロファイル以外の両方のユースケースに使用できません。 両方が必要な場合は、2 つの個別のキャンペーンを作成し、コンテキストに基づいてトリガーするキャンペーンを呼び出し元のシステムが決定するようにします。

&#x200B;* **フィードバックとトラッキングのデータセット** -  高スループットキャンペーンのフィードバックとトラッキングデータは、プロファイルに対して有効になっていない専用のデータセットに保存されます。 その結果、一致するプロファイルが存在する場合でも、これらのイベントはプロファイルにステッチされません。

  使用されるデータセットは次のとおりです。

   &#x200B;* **AJO メッセージフィードバックイベントデータセット - プロファイル以外**
   &#x200B;* **AJO メールトラッキングエクスペリエンスイベントデータセット - プロファイル以外**

&#x200B;* **スループットの割り当て** - 高スループットアドオンでプロビジョニングしたスループットは、高スループットキャンペーン専用に予約されます。 標準のキャンペーンと高スループット API トリガーキャンペーン間でスループットは共有されません。

## 標準のキャンペーンと高スループットキャンペーンの選択

次の表を使用して、ユースケースに適合する API トリガーキャンペーンタイプを判断します。

| 機能／要件 | 標準の API トリガーキャンペーン | 高スループットキャンペーン |
|------------------------|---------------------------------|---------------------------|
| **対象** | 基本製品に含まれます | 高スループットトランザクションメッセージアドオンが必要です。 |
| **スループット** | 1 秒あたり最大 500 トランザクション | 最大5000 TPS （電子メール）、最大1500 TPS （プッシュ通知） |
| **チャネル** | メール, SMS, プッシュ | 電子メール、プッシュ |
| **パーソナライゼーション** | API ペイロードのプロファイル + コンテキスト | API ペイロードのみのコンテキスト |
| **プロファイルとステッチ** | プロファイルにステッチされたイベントが存在するか、作成されます | プロファイルなし |
| **メッセージボリューム** | 標準の使用権限とメッセージパック | 個別の階層化されたメッセージボリューム |
| **インフラストラクチャ** | スタンダード | 拡張 |
| **稼動時間** | 99.9％ | 99.99％ |
| **ヘルスチェック API** | ○ | ○ |

つまり、次のようになります。

&#x200B;* 次の場合は、**標準の API トリガー**&#x200B;キャンペーンを選択します。
   &#x200B;* 高スループットを契約していない。
   &#x200B;* スループットのニーズは≤500 TPSです。
   &#x200B;* アドビのプロファイルに基づいたパーソナライゼーションが必要である。
   &#x200B;* 今後のターゲティングのために、キャンペーンデータをプロファイルにステッチする必要がある。
   &#x200B;* SMS メッセージが必要です。

&#x200B;* 次の場合は、**高スループット**&#x200B;キャンペーンを選択します。
   &#x200B;* 500 TPS を超えるスループットが必要である。
   &#x200B;* プロファイルのステッチが不要である。
   &#x200B;* すべてのパーソナライゼーションを API ペイロードで渡すことができる。
   &#x200B;* 電子メールまたはプッシュ通知チャネルを使用する。

## 設定ガイドライン

高スループットキャンペーンを正しく設定するには、次のガイドラインに従います。

1. **電子メールの高スループットのみ** – 新しいIP プールを作成します。 [IP プールの作成方法の詳細情報](../configuration/ip-pools.md)
1. 新しいチャネル設定を作成します。 [詳しくは、チャネル設定の指定方法を参照してください](../configuration/channel-surfaces.md)。
1. アドビカスタマーケアに連絡して、アクティブ化されたサーフェスを高スループット機能にマッピングするようにリクエストします。 チャネル設定とIP プールの詳細（メール用）を、組織IDとともに指定します。

>[!IMPORTANT]
>
>高スループットのトランザクションメッセージ用に指定されたチャネル設定は、その目的でのみ使用し、API トリガーのキャンペーンまたはジャーニーを使用する標準のトランザクションメッセージでは使用しない必要があります。 電子メールの高スループットの場合、この目的のために指定されたIP プールも、高スループット送信にのみ使用する必要があります。
