# メールスタイルの基本を学ぶ {#get-started-email-style}

[!DNL Journey Optimizer] でメールコンテンツの作成を開始すると、E メールデザイナーの&#x200B;**[!UICONTROL スタイル]**&#x200B;パネルで多数のスタイルパラメーターおよび属性を調整できます。

変更内容は、メールの本文、構造コンポーネント、コンテンツコンポーネントのいずれかに適用できます。

メール内の任意の要素を選択し、「**[!UICONTROL スタイル]**」タブをクリックします。 選択した要素のすべてのスタイルオプションが右側のパネルに表示されます。

![](assets/email_designer_styles.png)

例えば、テキストコンポーネントを選択した場合、次の操作を実行できます。

* その段落の&#x200B;**[!UICONTROL 背景色]**&#x200B;と&#x200B;**[!UICONTROL フォントカラー]**&#x200B;を調整できます。
* フォントファミリー、サイズ、高さ、整列などの&#x200B;**[!UICONTROL テキスト]**&#x200B;パラメーターを更新し、**[!UICONTROL インデント]**&#x200B;設定を使用して行頭文字の前の間隔を管理できます。
* また、テキストコンポーネントの&#x200B;**[!UICONTROL 境界線]**、**[!UICONTROL 余白]**、**[!UICONTROL パディング]**&#x200B;などのオプションも調整できます。

デフォルトの[コンテンツテンプレート](use-email-templates.md)を使用している場合や、メールにテーマを適用している場合は、選択したテーマと一致するように、いくつかのスタイル設定のみを調整できます。 [テーマの詳細情報](apply-email-themes.md)

![](assets/email_designer_styles_theme.png)

メールで一部の特定のスタイル設定を調整する方法については、次のリンクを参照してください。

* [メールの背景のパーソナライズ](backgrounds.md)
* [垂直方向の整列とパディングの調整](alignment-and-padding.md)
* [インラインスタイル属性の追加](inline-styling.md)方法を学ぶ
* [メールコンテンツへのカスタム CSS の追加](custom-css.md)方法を学ぶ
* [ダークモードコンテンツの管理](dark-mode.md)方法を学ぶ
