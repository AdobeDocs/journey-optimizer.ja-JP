# AIを活用したブランド修正 {#brand-corrections}

>[!AVAILABILITY]
>
>この機能はAdobe Journey Optimizerで利用でき、プッシュ、SMS、Web コンテンツチャネルに適用されます。

## 概要 {#overview}

ブランドのQA中にコンテンツにフラグが付けられた場合、Adobe Journey Optimizerは生成AIを使用して、修正または改善されたテキストの代替案を自動的に生成できます。 フラグの付いたコピーを手作業で書き換える代わりに、ブランドガイドラインに沿ったインライン提案を受け取ります。このガイドラインは、ワンクリックでレビュー、プレビュー、適用できます。

これにより、ブランドのQA ステップが、ブロッキングされたレビューゲートから&#x200B;**進みながら修正できるエクスペリエンス**&#x200B;に変わり、手作業による修正に費やす時間が削減され、チャネルをまたいだコンテンツ制作が高速化されます。

この機能は、制作ワークフローを遅らせることなく、膨大なマルチチャネルのキャンペーンをまたいでブランドコンプライアンスを維持する必要があるコンテンツマーケター、コピーライター、キャンペーンオペレーター向けに設計されています。

## 仕組み {#how-it-works}

Adobe Journey Optimizerのブランド QAは、トーンオブボイス、用語、メッセージ基準、編集ルールなど、組織のブランドガイドラインに照らし合わせてコンテンツを評価します。 違反または品質の問題が検出されると、システムは影響を受けるコンテンツ要素にフラグを付け、サポートされている場合は、Adobe生成AI エンジンを使用して推奨される置換を自動的に生成します。

エンドツーエンドのフローは次のとおりです。

1. **ブランド QA スキャン** — コンテンツ（プッシュ通知本文、SMS メッセージ テキスト、またはWeb コンテンツブロック）に対してブランドチェックを実行すると、システムは各要素をアクティブなブランドルールと比較して評価します。
2. **違反の検出** — 1つ以上のブランド基準に失敗した要素には、重大度インジケーター（重要、警告、提案など）がフラグ付けされます。
3. **AIの提案の生成** — フラグが設定された各要素について、1つ以上の修正されたテキスト代替案が自動的に生成されます。 提案は、Adobeの生成AI エンジンによって生成されます。このエンジンは、違反の理由とブランドのガイドラインのコンテキストの両方を認識しています。
4. **インラインプレビュー** – 提案された置換テキストが、フラグ付きの元のテキストと直接並べてインラインで表示されます。 変更を加える前に、元のバージョンと提案されたバージョンを並べて比較できます。
5. **ワンクリックで適用** – 提案がニーズを満たしている場合は、**適用**&#x200B;を選択して、フラグ付きテキストをAI生成バージョンに置き換えます。 コンテンツエディターがすぐに更新され、ブランドフラグがクリアされます。
6. **手動オーバーライド** — AIの提案にロックされることはありません。 提案を適用する前に編集したり、提案を却下して独自の修正を書いたり、コンテキストで例外が保証されている場合はフラグを完全に無視したりできます。

>[!NOTE]
>
>AIが生成した提案はレコメンデーションのみです。 編集作業は完全に管理されます。 提案を適用する前に、必ずキャンペーンのコンテキストで提案を確認してください。

## 前提条件 {#prerequisites}

AIによるブランド補正を使用する前に、次の条件が満たされていることを確認してください。

- **ブランドガイドラインが設定されました** – 組織には、少なくとも1つのアクティブなブランドプロファイルがAdobe Journey Optimizerで設定されている必要があります。 ブランドプロファイルは、コンテンツを評価する際のルールを定義します。 Adobeの管理者またはブランドマネージャーに連絡して、ブランドプロファイルが公開され、サンドボックスに関連付けられていることを確認します。
- **コンテンツ AI機能が有効** – 組織とサンドボックスに対してAIを活用したコンテンツ支援を有効にする必要があります。 これは、Adobe Admin Consoleの商品プロファイルレベルで管理されます。 ブランドスキャン後にAIの提案が表示されない場合は、AI コンテンツ生成の使用権限が有効であることを管理者に確認します。
- **サポートされているコンテンツの種類** — AIによる提案を含むブランド補正は、Journey Optimizer Web Designerを通じて編集されたプッシュ通知のタイトルと本文、SMS メッセージテキスト、およびWeb コンテンツブロックのコンテンツタイプでサポートされています。 リッチメディアアセット（画像、動画）はブランドコンプライアンスについて個別に評価され、テキストレベルのAI修正の範囲にはありません。
- **権限の編集** – フラグ付きコンテンツが格納されているジャーニー、キャンペーン、またはコンテンツテンプレートへの編集アクセス権が必要です。

## 設定 {#configure}

組織が既にブランド QAを使用している場合、AIを活用したブランド修正を有効にするために追加の設定は必要ありません。 AI提案レイヤーは、サポートされているコンテンツタイプでブランド違反が検出されると自動的にアクティブ化されます。

ブランドチェックを実行し、AIの提案にアクセスするには：

1. Adobe Journey Optimizerでキャンペーンまたはジャーニーを開きます。
2. 関連するチャネル（プッシュ、SMS、またはWeb）のコンテンツステップに移動します。
3. **ブランドの整合性を確認**&#x200B;を選択します（または、コンテンツエディターツールバーから&#x200B;**ブランド QA** パネルを開きます）。
4. スキャンが完了するまでお待ちください。 フラグ付き要素はキャンバスでハイライト表示され、右側の&#x200B;**ブランドの問題** パネルに表示されます。
5. フラグが設定された各アイテムについて、問題行を展開して、違反の理由とAIが生成した提案を表示します。
6. **プレビュー**&#x200B;を使用して、コンテンツキャンバスでレンダリングされた推奨テキストを表示します。
7. 「**提案を適用**」を選択してフラグ付きテキストを置き換えるか、「**編集**」を選択して提案を変更してから適用します。
8. すべての問題が解決または確認されたら、ブランドチェックを再実行してコンプライアンスを確認します。

>[!NOTE]
>
>提案を適用すると、エディターのライブコンテンツが更新されますが、キャンペーンは自動的に公開またはアクティブ化されません。 残りのキャンペーン設定とアクティベーションの手順を通常どおりに完了する必要があります。

### 複数の提案の操作 {#multiple-suggestions}

違反によっては、AI エンジンが複数の代替案を生成する場合があります。 このような場合、**ブランドの問題** パネルにオプションの番号付きリストが表示されます。 前後の矢印を使用して、最適な矢印を選択する前に、代替案を順を追って選択します。 それぞれの選択肢は異なるスタイルのアプローチで生成されます。たとえば、ある選択肢は簡潔さを優先し、別の選択肢はトーンの調整を重視するといった具合です。

### 一括修正 {#bulk-corrections}

同じコンテンツ内の複数の要素にフラグが設定されている場合は、個別に提案を適用するか、**ブランドの問題** パネルの上部にある&#x200B;**すべての提案を適用** アクションを使用して、AIが生成したすべての置換を1つのステップで受け入れることができます。 一括適用を使用する前に、リストを注意深く確認してください。この操作は、すべてのフラグ付きテキストを同時に置き換えます。

>[!NOTE]
>
>一括適用は、すべてのフラグ付き項目にAIの提案が関連付けられている場合にのみ使用できます。 提案がない項目（画像の準拠フラグなど）はスキップされ、手作業によるレビュー用にフラグが付けられます。
