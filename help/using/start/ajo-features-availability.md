# Journey Optimizerの機能 {#ajo-features-availability}

>[!BEGINSHADEBOX]

**このページで：**&#x200B;使用可能な[!DNL Adobe Journey Optimizer]機能、それぞれのライフサイクルステージ（一般提供、限定提供、またはBeta）、それらが適用される基本オファー、発送時について確認します。「*」に答えましょう。「これを使用できますか？」* リリースノートを掘り下げることなく。

>[!ENDSHADEBOX]

このページでは、[!DNL Adobe Journey Optimizer]全体で利用可能な機能が統合されているため、実装前のスコープで使用できる機能を確認できます。 機能は、機能領域ごとにグループ化されています。 各機能には、現在のライフサイクルステータス、適用されるベースオファー、利用可能になった日付、設定や地域の制限に関するメモが記載されています。

*列以降で*&#x200B;利用可能な&#x200B;**Core capability**&#x200B;とマークされた行は、2026年以前から一般に利用可能だった、長期的な基本機能です。 日付のある行は、2026年に出荷された変更を反映しています。

>[!IMPORTANT]
>
>**環境に機能が表示されないのはなぜですか？** **制限付き可用性**&#x200B;または&#x200B;**Beta**&#x200B;の機能は、すべてのユーザーには表示されません。最初に、制限された組織のセットにロールアウトされます。 読み上げた機能が環境に表示されない場合は、以下のステータスを確認してください。ステータスが&#x200B;**LA**&#x200B;または&#x200B;**Beta**&#x200B;の場合は、Adobe担当者にお問い合わせください。 ここに記載されている機能は、お使いの環境で有効になっていることを意味しません。

>[!NOTE]
>
>**可用性と使用権限** このページでは、*機能のライフサイクルと可用性*&#x200B;を追跡します（機能が出荷されたかどうか、どの成熟度で）。 機能が&#x200B;*ライセンスに含まれるかどうかは、基本オファーとアドオンによって異なります。[&#x200B; パッケージと機能](ajo-packages.md)を参照してください。*

## ライフサイクルステータスの意味 {#status-definitions}

| ステータス | 意味 |
|--------|--------------|
| **GA** – 一般提供 | すべての環境にリリースされます。 この機能を含むライセンスを持つすべての組織で使用できます。 |
| **LA** – 利用制限 | 一部の組織に対してリリースされました。 **Adobeの担当者**&#x200B;に連絡してアクセスをリクエストしてください。 |
| **Beta** | 評価のための早期アクセスリリース。 一般公開前に変更される可能性があります。 オプトインが必要な場合があります。 |

## ベースオファーに対する「適用先」マップの方法 {#applies-to}

**適用先**&#x200B;列は、3つの[!DNL Adobe Journey Optimizer]基本オファーを参照します。

- **Journey Optimizer - キャンペーン** — バッチ、オーディエンスベースのオーケストレーション
- **Journey Optimizer - ジャーニー** — リアルタイムのイベント駆動型オーケストレーション
- **Journey Optimizer - キャンペーンとジャーニー** – 両方

「**すべての基本オファー**」とマークされたチャネル、コンテンツ、およびプラットフォーム機能は、基本オファーに関係なく利用できますが、ほとんどの場合、関連するチャネルまたは高度な機能のアドオンが必要です。 使用権限の詳細については、[&#x200B; パッケージと機能](ajo-packages.md)を参照してください。
