# Adobe Journey Optimizerのパッケージと機能 {#ajo-packages}

>[!BEGINSHADEBOX]

**このページでは、** モジュール式Adobe Journey Optimizer パッケージの手順を順を追って説明します。基本オファーの選択、チャネルの追加、高度な機能の追加を順を追って説明し、適切な設定と顧客エンゲージメントの方法を一致させることができます。

>[!ENDSHADEBOX]

[!DNL Adobe Journey Optimizer]はモジュール式パッケージ モデルを使用しています。 主要なオーケストレーションのユースケースに一致する基本オファーから開始し、必要なチャネルと高度な機能を追加します。

>[!NOTE]
>
>機能の可用性は、ライセンス契約、選択したアドオン、地域の可用性、チャネル設定、実装の前提条件によって異なる場合があります。 お客様の組織に固有の詳細については、Adobeの担当者にお問い合わせください。

## ステップ 1：ベースオファーの選択 {#base-offers}

3つの基本オファーが利用可能です。 主に顧客とやり取りする方法に最も適したものを選びましょう。

| ベースオファー | 最適な用途 | この記事の内容 |
|-----------|---------|-----------------|
| **Journey Optimizer - キャンペーン** | マーケターが計画したアウトリーチの一括送信 | オーディエンスベースのスケジュール型キャンペーンオーケストレーションにより、バッチエンゲージメントとマーケターによるアウトリーチを計画。 |
| **Journey Optimizer - ジャーニー** | リアルタイムの顧客エンゲージメント | イベント駆動型の1:1 ジャーニーオーケストレーションによるリアルタイムの顧客エンゲージメント。 |
| **Journey Optimizer - キャンペーンとジャーニー** | 両方を必要とするお客様 | オーディエンスベースのキャンペーンオーケストレーションとリアルタイムのジャーニーオーケストレーションの両方を含むオファー。 |

### キャンペーンとジャーニーの違い？ {#campaigns-vs-journeys}

| 機能 | Journey Optimizer - Campaigns | Journey Optimizer -ジャーニー | Journey Optimizer - キャンペーンとジャーニー |
|--|:-----------------------------:|:----------------------------:|:----------------------------------------:|
| オーディエンスベースのバッチオーケストレーション | ✓ | — | ✓ |
| リアルタイムイベント駆動型オーケストレーション | — | ✓ | ✓ |
| 利用可能なチャネルアドオン | ✓ | ✓ | ✓ |
| 決定アドオンが利用可能 | ✓ | ✓ | ✓ |

### 「キャンペーン」はいつ選択すればよいですか？ {#when-to-choose-campaigns}

主なユースケースが次の場合は、**Journey Optimizer - キャンペーン**&#x200B;を選択します。

- 予定されたキャンペーン
- オーディエンスベースのアウトリーチ
- バッチマーケティングワークフロー
- マーケター主導のエンゲージメントプログラム

### ジャーニーはいつ選べばいいですか？ {#when-to-choose-journeys}

主なユースケースが次の場合は、**Journey Optimizer - ジャーニー**&#x200B;を選択します。

- イベントをトリガーとしたコミュニケーション
- イベント後のフォローアップフロー
- オンボーディングとライフサイクルジャーニー
- リアルタイム 1:1 エンゲージメント

### 「キャンペーンとジャーニー」はいつ選択すればよいですか？ {#when-to-choose-both}

両方が必要な場合は、**Journey Optimizer - キャンペーンとジャーニー**&#x200B;を選択します。

- バッチオーディエンスベースのオーケストレーション
- リアルタイムイベント駆動型オーケストレーション

## ステップ 3 – 高度な機能を追加する {#advanced-capabilities}

**一般的な機能は次のとおりです。**
- 適格性ルールと制約にもとづくオファーの選択

- AIを活用したランキングモデル。ライセンス済み
- サポートされているキャンペーン、ジャーニー、コードベースのエクスペリエンスをまたいだ意思決定

## よくある質問 {#faq}

+++**すべての基本オファーには、すべてのチャネルが含まれますか？**

いいえ。 ベースオファーでオーケストレーション機能を定義します。 チャネルアクセスは、組織のアドオンとライセンス設定によって異なります。

+++

+++**キャンペーンとジャーニーの違いは何ですか？**

**キャンペーン**&#x200B;は、オーディエンスベースおよびマーケターが計画したものです。 日次アウトリーチ、プロモーションプログラム、バッチキャンペーンワークフローに最適です。

**ジャーニー**&#x200B;はリアルタイムでイベント駆動型です。 顧客の行動に反応する1:1回のエンゲージメントに最適です。

**キャンペーンとジャーニー**&#x200B;には、両方のオーケストレーションモデルが含まれています。

+++

+++**オーケストレーションされたキャンペーンでサポートされているチャネルはどれですか？**

オーケストレーションキャンペーンは、キャンペーンオーケストレーションワークフローに使用されるチャネルのサブセットをサポートします。 チャネルの可用性は、ライセンス設定によって異なります。 [&#x200B; オーケストレーションされたキャンペーンについて詳しく見る](../orchestrated/gs-orchestrated-campaigns.md)

+++

+++**すべての設定に決定機能が含まれていますか？**

いいえ。 Decisioningは、高度な機能を備えた個別のアドオンです。 [決定機能の使用方法を学ぶ](../experience-decisioning/gs-experience-decisioning.md)

+++

+++**Select、Prime、またはUltimateについて聞いたことがあります。 これらは現在のパッケージ モデルですか？**

[!DNL Adobe Journey Optimizer]は、基本オファーとアドオンを中心に構築されたモジュール式パッケージモデルを通じて提供されるようになりました。 従来のパッケージ用語を使用している既存のお客様の場合は、Adobe担当者に連絡して、現在の使用権限を確認してください。
