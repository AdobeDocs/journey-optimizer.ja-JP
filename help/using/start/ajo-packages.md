# Adobe Journey Optimizerのパッケージと機能 {#ajo-packages}

>[!BEGINSHADEBOX]

**このページ：**&#x200B;では、基本オファー、チャネルアドオン、Decisioning アドオンをまたいで、Adobe Journey Optimizer パッケージのモジュール化がどのように機能するかを説明します。これにより、エンゲージメントのユースケースと予算に合った組み合わせを選択できます。

>[!ENDSHADEBOX]

[!DNL Adobe Journey Optimizer]はモジュール式パッケージ モデルを使用しています。 主要なユースケースに一致する基本オファーから開始し、必要なチャネルと高度な機能を追加します。

>[!TIP]
>
>**使用しているモデルが不明ですか？** モジュラーパッケージモデルで[!DNL Adobe Journey Optimizer]を購入した場合、このページで説明されている基本オファーとアドオンが適用されます。 契約書で&#x200B;**Select**、**Prime**、または&#x200B;**Ultimate**&#x200B;が参照されている場合は、レガシーパッケージモデルを利用しています。現在の使用権限を確認するには、Adobe担当者にお問い合わせください。

>[!NOTE]
>
>パッケージの可用性と含まれる機能は、契約書、選択したアドオン、地域の可用性によって異なります。 お客様の組織に固有の詳細については、Adobeの担当者にお問い合わせください。

## 簡単な回答 {#quick-answers}

読む前にほとんどの人が抱いている2つの質問。 [完全なFAQ](#faq)は、ページの下部にあります。

+++**すべての基本オファーには、すべてのチャネルが含まれますか？**

いいえ。 [!DNL Adobe Journey Optimizer]はモジュラーモデルを使用しています。ベースオファーによってオーケストレーション機能（キャンペーン、ジャーニー、またはその両方）が決まり、チャネルアドオンによってエンゲージできるメッセージングサーフェスが決まります。 ユースケースと予算に合わせて、最適な組み合わせを選択できます。

+++

+++**キャンペーンとジャーニーの違いは何ですか？**

**キャンペーン**&#x200B;は、オーディエンスベースでマーケターが計画するものです。オーディエンスを定義し、メッセージを作成し、バッチ送信としてスケジュールまたはトリガー化します。 これらは、プロモーションのアウトリーチ、ニュースレター、マルチステップのオーディエンスワークフローに最適です。

**ジャーニー**&#x200B;はリアルタイムでイベント主導であり、個々の顧客行動をリアルタイムで受け止め、顧客接点をまたいで1:1のエクスペリエンスを調整します。 オンボーディングフロー、購入後のシーケンス、リアルタイムのトリガーメッセージに最適です。

**キャンペーンとジャーニー**&#x200B;では、両方の機能が1つのライセンスで提供されます。

+++

## ステップ 1：ベースオファーの特定 {#base-offers}

>[!NOTE]
>
>**Journey Optimizerの評価中ですか？** このステップで、エンゲージメント戦略に最適なベースオファーを選択します。 **既にお客様ですか？** これは、どのベースオファーを持ち、何をするかを確認する方法です。

3つの基本オファーが利用可能です。 それぞれ異なる方法で顧客を惹きつけることができます。

| ベースオファー | 最適な用途 | コア動作 |
|-----------|---------|--------------|
| **Journey Optimizer - キャンペーン** | マーケターが計画したアウトリーチの一括送信 | オーディエンスベースのスケジュール済みオーケストレーション： バッチエンゲージメントとマーケターが計画したアウトリーチのための、単一またはマルチステップのキャンペーンワークフロー。 |
| **Journey Optimizer - ジャーニー** | リアルタイムの顧客エンゲージメント | イベント駆動型、1:1 オーケストレーション。 リアルタイムのジャーニーとスケジュールされたジャーニーの両方に対応します。 |
| **Journey Optimizer - キャンペーンとジャーニー** | 両方を必要とするお客様 | オーディエンスベースのキャンペーンオーケストレーションとリアルタイムのジャーニーオーケストレーションを組み合わせて活用。 |

>[!IMPORTANT]
>
>**ストレージ使用権限はパッケージによって異なります。** 合計データボリュームの使用権限は、基本オファーによって異なります。**キャンペーン**&#x200B;のお客様は、アドレス可能なプロファイルごとに&#x200B;**15 KB**&#x200B;を受け取り、一方、**ジャーニー**&#x200B;および&#x200B;**キャンペーンとジャーニー**&#x200B;のお客様は、アドレス可能なプロファイルごとに&#x200B;**75 KB**&#x200B;を受け取ります。 パッケージを選択または確認する際に、これを考慮します。

### キャンペーンとジャーニーの違い？ {#campaigns-vs-journeys}

| | Journey Optimizer - Campaigns | Journey Optimizer -ジャーニー | Journey Optimizer - キャンペーンとジャーニー |
|--|:-----------------------------:|:----------------------------:|:----------------------------------------:|
| オーディエンスベースのバッチオーケストレーション | ✓ | 限定的¹ | ✓ |
| リアルタイムイベント駆動型オーケストレーション | — | ✓ | ✓ |
| トランザクションメッセージ（電子メール、プッシュ、SMS） | ✓ | ✓ | ✓ |
| 利用可能なチャネルアドオン | ✓ | ✓ | ✓ |
| 決定アドオンが利用可能 | ✓ | ✓ | ✓ |

¹ **Journey Optimizer - ジャーニー**&#x200B;では、オーディエンスベースのオーケストレーションは、スタンドアロンのバッチキャンペーンではなく、ジャーニーのユースケース内でのみサポートされます。

## ステップ 2 – 必要なチャネルを追加する {#channel-addons}

チャネルは、基本オファーにバンドルされません。 エンゲージメント戦略に合ったチャネルアドオンまたはアドオンバンドルを選択します。

>[!BEGINTABS]

>[!TAB ✉️ アウトバウンド配信]

アウトバウンドメッセージチャネルを通じてオーディエンスにリーチ。

**含まれるメール：**、プッシュ通知、ダイレクトメール

**一般的な使用例：** プロモーションメール、トランザクションプッシュアラート、物理的なメールキャンペーン

**サポートされているサーフェス：**&#x200B;受信箱、モバイルデバイスのロック画面/通知トレイ、郵便番号

新しいインスタンスでのIP ウォーミングのサポートに関する配信品質の基本が含まれます。 継続的なモニタリングとコンサルタント主導のサポートについては、3つの&#x200B;**配信品質パッケージ** （Essentials、Enhanced、Plus）が個別のアドオンとして利用できます。 [配信品質の詳細](../reports/deliverability.md)

>[!TAB 📱 モバイル ]

セッション中および永続的なモバイルエクスペリエンスでアプリユーザーを惹きつけます。

**アプリ内メッセージ、プッシュ通知、コンテンツカード、モバイルサーフェス用のコードベースのチャネルが**&#x200B;個含まれます

**一般的なユースケース：** オンボーディングフロー、機能のお知らせ、ロイヤルティナッジ、リアルタイムのアプリ内オファー

**サポートされているサーフェス：**&#x200B;個のモバイルアプリ画面、通知トレイ、永続的なコンテンツスロット、SDK経由のカスタムアプリサーフェス

>[!TAB 🌐 Web]

コードをデプロイすることなくweb エクスペリエンスをパーソナライズ。

**含まれるweb チャネル （ビジュアル エディターと非ビジュアル エディター）、web サーフェス用のコードベースのチャネル：**

**一般的な使用例：** ホームページ バナー、ランディングページのパーソナライゼーション、A/B テスト、API経由のヘッドレス web パーソナライゼーション

**サポートされているサーフェス：** ブラウザーページ、シングルページアプリ（SPA）、ヘッドレス web エンドポイント

>[!TAB 📦すべてのチャネル ]

**すべてのチャネル** アドオンは、1回の購入でアウトバウンド配信+ モバイル + Webをバンドルします。

**電子メール、プッシュ通知、ダイレクトメール、アプリ内メッセージ、コンテンツカード、web チャネル、コードベースの3つの個別アドオンのすべてのチャネルが**&#x200B;含まれます

**一般的なユースケース：**&#x200B;は、アウトバウンド、モバイルアプリ、webをまたいで調整されたオムニチャネルプログラムです。例えば、アプリ内メッセージとパーソナライズされたweb バナーを含む電子メールをフォローアップするキャンペーンです

**サポートされているサーフェス：**&#x200B;すべてのサーフェス（アウトバウンド配信、モバイル、およびWeb アドオン）

>[!NOTE]
>
>**すべてのチャネル** バンドルは、通常、アウトバウンド配信、モバイル、およびWebを個別にライセンス供与するよりも費用対効果が高くなります。 これら3つすべてを使用する場合は、Adobeの担当者にバンドル価格を個々のアドオンと比較するように依頼してください。

>[!ENDTABS]

### その他のチャネル {#additional-channels}

ひとつのチャンネルがアドオンと関連付けられていない場合もあります。 そうしたツールの利用は、ライセンス取得済みの設定や契約書、パートナーチャネルにはサードパーティのビジネスアカウントを必要とします。

**📲SMS / MMS** — テキストおよびマルチメディアメッセージを携帯電話番号に送信します。 トランザクション SMS （リアルタイム、イベントトリガー）は、すべてのベースオファーでサポートされています。SMS/MMSのマーケティング利用の拡大は、ライセンス済みの設定によって異なります。 [ モバイルメッセージの送信方法を学ぶ](../mobile/get-started-mobile.md)

**💬WhatsApp** — WhatsApp Businessを通じてメッセージを送信します。 WhatsApp Business アカウントが必要です。使用可能かどうかは、契約書とライセンス設定によって異なります。 [WhatsAppの使用方法を学ぶ](../whatsapp/get-started-whatsapp.md)

>[!NOTE]
>
>SMS/MMSおよびWhatsAppの可用性をAdobe担当者にお問い合わせください。これらのチャネルは、標準のアウトバウンドデリバリー、モバイル、web アドオンの一部ではありません。

## ステップ 3 – 高度な機能を追加する {#advanced-addons}

### 決定 {#decisioning-addon}

**Decisioning** アドオンを使用すると、チャネルを問わず、各プロファイルに最適なオファー、アクション、またはエクスペリエンスをリアルタイムで定義、管理、配信できます。

**ロック解除するもの：**
- 適格性ルール、ランキングロジック、制約を使用したリアルタイムのオファー選択
- AIを活用したランキングモデルにより、オファーのパフォーマンスを自動的に最適化
- ジャーニー、キャンペーン、コードベースのエクスペリエンスで使用できるポリシーの決定

**3つの基本オファーすべてで**&#x200B;利用できます。使用許諾契約に従います。 [決定の使用方法を学ぶ](../experience-decisioning/gs-experience-decisioning.md) | [AI モデルについて学ぶ](../offers/ranking/ai-models.md)

## 一目で比較 {#comparison-matrix}

機能は2つのテーブルに分割されるので、各テーブルをスキャンしやすくなります。オーケストレーション機能は&#x200B;**基本オファー**&#x200B;によって決定され、チャネルと高度な機能は&#x200B;**アドオン**&#x200B;によってロック解除されます。

### オーケストレーション機能 {#orchestration-capabilities}

ベースオファーで決定。

| 機能 | キャンペーン | ジャーニー | キャンペーンとジャーニー |
|-----------|:---------:|:--------:|:--------------------:|
| トランザクションメッセージ（電子メール、プッシュ、SMS） | ✓ | ✓ | ✓ |
| バッチキャンペーン | ✓ | — | ✓ |
| オーケストレーションされたキャンペーン _（電子メール、SMS、プッシュ、ダイレクトメールのみ）_ | ✓ | — | ✓ |
| ジャーニーの自動化 | — | ✓ | ✓ |
| リアルタイムのイベントトリガー | — | ✓ | ✓ |

### チャネルと高度な機能 {#channel-capabilities}

ほとんどのチャネルは、3つの基本オファーすべてで利用でき、リストされているアドオンが必要です。 SMS/MMSやWhatsAppなど、一部の機能は、ライセンス取得済みの設定によって異なります。

| 機能 | 対象 | アドオンは必須です |
|-----------|-------------|----------------|
| メール | すべての基本オファー | アウトバウンド配信 |
| プッシュ通知 | すべての基本オファー | アウトバウンド配信 |
| ダイレクトメール | すべての基本オファー | アウトバウンド配信 |
| SMS／MMS | オプションを追加します | オプションを追加します |
| アプリ内メッセージ | すべての基本オファー | モバイル |
| コンテンツカード | すべての基本オファー | モバイル |
| Web チャネル | すべての基本オファー | Web |
| コードベースのエクスペリエンス | すべての基本オファー | モバイル / Web |
| WhatsApp | オプションを追加します | WhatsApp |
| 決定 | ライセンスによって異なります | 決定 |
| AIを活用したランキング | ライセンスによって異なります | 決定 |

>[!NOTE]
>
>**トランザクションメッセージとチャネルアドオンの比較** 基本的なトランザクションメッセージ（イベントをトリガーにした電子メール、プッシュ通知、SMS）は、あらゆるベースオファーに含まれます。 **アウトバウンド配信**、**モバイル**、**Web**&#x200B;のアドオンを使用すると、上記の追加のサーフェスとともに、これらのチャネルを完全にマーケティングおよびキャンペーンで使用できるようになります。

## よくある質問 {#faq}

+++**オーケストレーションされたキャンペーンでサポートされているチャネルはどれですか？**

オーケストレーションされたキャンペーン（キャンペーンオーケストレーション機能を使用するマルチステップのオーディエンスワークフロー）は、**電子メール、SMS、プッシュ通知、ダイレクトメール**&#x200B;のみをサポートします。 web、アプリ内、コードベース、コンテンツカードの各チャネルは、オーケストレーションされたキャンペーンワークフローではサポートされていません。

+++

+++**すべての設定に決定機能が含まれていますか？**

いいえ。 決定機能は個別の高度な機能アドオンであり、デフォルトではベースオファーには含まれません。 設定にDecisioningを追加するには、Adobe担当者にお問い合わせください。

+++

+++**Select、Prime、またはUltimateについて聞いたことがあります。 これらは現在のパッケージ モデルですか？**

[!DNL Adobe Journey Optimizer]は、基本オファー（キャンペーン、ジャーニー、キャンペーン、ジャーニー）とアドオンを中心に構築されたモジュール式パッケージモデルを通じて提供されるようになりました。 Select、Prime、またはUltimateの用語を使用している既存のお客様の場合は、機能参照については、以下の[従来のパッケージ ](#legacy-packaging)を参照するか、現在の使用権限についてAdobe担当者にお問い合わせください。

+++

**パッケージの概要**

**Ultimate** — Primeのすべての機能に加えて、決定と高度な最適化が含まれます。

- リアルタイムのオファー決定とパーソナライゼーション
- AIを活用したランキングと最適化モデル
- 高度なレポート機能と検証機能
