# 自分の[!DNL Adobe Journey Optimizer] パッケージで利用できるもの？ {#ajo-packages}

[!DNL Adobe Journey Optimizer]機能は、使用許諾契約、有効なチャネル、ユーザー権限によって異なります。 このガイドでは、パッケージで通常利用できる機能を理解し、各機能の製品ドキュメントに直接移動します。

また、利用可能な環境は、チャネルの設定、実装の前提条件、購入したアドオンなどによって異なります。 ライセンスモデルに一致するタブを選択します。

>[!BEGINTABS]

>[!TAB ジャーニーとキャンペーン ]

このタブは、現在の[!DNL Adobe Journey Optimizer] モジュラーパッケージモデル（Journey Optimizer - キャンペーン、Journey Optimizer - ジャーニー、またはJourney Optimizer - キャンペーンとジャーニー）でライセンスを取得したお客様に適用されます。

## ベースパッケージ {#current-packages}

| パッケージ | この記事の内容 |
|---------|----------------|
| **Journey Optimizer - キャンペーン** | キャンペーンオーケストレーション：バッチエンゲージメント用のシングルまたはマルチステップのオーディエンスワークフロー。 電子メール、プッシュ通知、SMSを含むトランザクションメッセージ。 |
| **Journey Optimizer - ジャーニー** | リアルタイムJourney Orchestration：ストリーミングとバッチ処理をサポートするイベントトリガージャーニー 電子メール、プッシュ通知、SMSを含むトランザクションメッセージ。 |
| **Journey Optimizer - キャンペーンとジャーニー** | Campaign OrchestrationとReal-time Journey Orchestrationを組み合わせたものです。 電子メール、プッシュ通知、SMSを含むトランザクションメッセージ。 |

>[!NOTE]
>
>合計データボリュームの使用権限はパッケージによって異なります：**キャンペーン**&#x200B;のお客様は、アドレス可能なプロファイルごとに15 KBの使用権限を付与されます。**ジャーニー**&#x200B;および&#x200B;**キャンペーンとジャーニー**&#x200B;のお客様は、アドレス可能なプロファイルごとに75 KBの使用権限を付与されます。

次のアドオンは、ベースパッケージの上にチャネルカバレッジを拡張します。 **すべてのチャネル** アドオンには、アウトバウンド配信、モバイル、Webがバンドルされています。

| アドオン | ロック解除されたチャネル |
|--------|----------------|
| **アウトバウンド配信** | 電子メール、プッシュ通知、ダイレクトメール。 メール配信の基本を含む。 |
| **モバイル** | モバイルサーフェス用のアプリ内メッセージ、プッシュ通知、コンテンツカード、コードベースのチャネル |
| **Web** | web サーフェス用のweb チャネルとコードベースのチャネル |
| **すべてのチャネル** | バンドルのアウトバウンド配信+ モバイル + Web |
| **決定** | リアルタイムのオファー決定とAIを活用した最適化 |

## パッケージの概要 {#package-summaries}

+++**選択**

バッチおよびトランザクションメッセージの使用を開始する組織に最適です。

- スケジュールされたバッチキャンペーンとトランザクションメッセージ
- 主要キャンペーンとジャーニーの実行
- 電子メール、SMS、プッシュ通知、カスタムアクションチャネルの基盤
- 標準オーケストレーションガードレール

+++

+++**Prime**

Selectのあらゆる機能に加えて、リアルタイムのオーケストレーションとインバウンドチャネルを備えています。

- リアルタイムのイベントトリガージャーニーオーケストレーション
- インバウンドチャネル：web、アプリ内メッセージ、コードベースのエクスペリエンス、コンテンツカード、ダイレクトメール
- 高度なオーディエンスのセグメンテーションとターゲティング

+++

+++**Ultimate**

Primeの能力に加えて、意思決定と高度な最適化を備えています。

- リアルタイムのオファー決定とパーソナライゼーション
- AIを活用したランキングと最適化モデル
- 高度なレポート機能と検証機能

+++
